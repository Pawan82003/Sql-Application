# SQL Application (Python)

## 📌 Description

A Python-based SQL application designed to perform basic database operations on employee records. The application allows users to interact with a SQLite database and execute CRUD (Create, Read, Update, Delete) operations efficiently.

## 🚀 Features

* Add new employee records
* View existing data
* Update employee details
* Delete records from the database

## 🛠️ Technologies Used

* Python
* SQLite
* SQL

## ⚙️ How to Run

1. Clone the repository:
   git clone https://github.com/Pawan82003/Sql-Application.git

2. Navigate to the project directory:
   cd Sql-Application

3. Install dependencies:
   pip install -r requirements.txt

4. Run the application:
   python app.py

## 🎯 Purpose

This project was developed to understand database integration with Python and practice SQL operations in a real-world scenario.
